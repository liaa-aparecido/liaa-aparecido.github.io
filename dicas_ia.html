📊 Lições aprendidas

O que funcionou — e o que não funcionou

✅ Funcionou bem

  • Kiro controlando Git, SSH e APIs — sem sair do chat
  • Manim para animações vetoriais profissionais
  • Edge TTS: voz neural PT-BR gratuita, 3 vozes distintas
  • ffmpeg para montar áudio + vídeo + trilha automaticamente
  • Pedir ao agente para verificar antes de commitar
  • Dividir o problema em cenas menores e iterar
  • Descrever o resultado esperado, não o como fazer

❌ Não funcionou / aprendizados

  • ElevenLabs bloqueou VM por detectar IP de servidor — usou Edge TTS
  • Vídeo cortava o áudio: -shortest parava no fim do vídeo, não do áudio
  • Texto saindo da tela: Manim não avisa — precisa checar área segura
  • Voz Thalita (Multilingual) mudava de idioma automaticamente no meio da narração
  • gTTS é robótico — só serve para protótipo, não para produto final
  • Render de 15.000 frames em 1920×1080 travou por timeout

💡 Regra que aprendi: Sempre medir a duração do áudio antes de renderizar o vídeo — não depois.

💡 Dicas práticas

5 dicas que você usa amanhã

🗂

Dê contexto, não comandos

Em vez de "escreva um script Python", diga "tenho logs do Suricata em JSON e quero cruzar com o filterlog usando Community ID — escreve o correlacionador". Quanto mais contexto, menos iterações.

🔁

Itere em cenas pequenas

Para vídeos: gere 1 cena, assista, ajuste, depois gere as outras. Não tente gerar tudo de uma vez — você vai perder tempo corrigindo 10 cenas erradas.

🎙

Edge TTS para narração gratuita

pip install edge-tts — vozes neurais da Microsoft, PT-BR, sem API key. Use pt-BR-AntonioNeural (masculina) e pt-BR-FranciscaNeural (feminina) para variar.

🧪

Peça ao agente para verificar

Após qualquer mudança importante, diga: "antes de commitar, verifica se o resultado está correto". O agente roda testes, mede durações, compara — e você evita publicar algo quebrado.

🔑

Nunca cole chaves no chat público

Use variáveis de ambiente ou arquivos .conf fora do repositório. Chaves no histórico do chat ou no GitHub são um risco real — mesmo em repositórios privados.

📏

Meça antes de assumir

Vídeo cortando? Mede o áudio com ffprobe antes de renderizar. Texto saindo da tela? Calcula as coordenadas antes de animar. IA não sabe o que não pode ver.
